# Omarchy Chicago Light

Chicago's 1893 World's Fair in warm limestone, lake green, and brass.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-chicago-light.git`, then run `omarchy theme set chicago-light`.

For the companion theme, see [Omarchy Chicago Dark](https://github.com/jacob-vincent-mink/omarchy-chicago-dark).
