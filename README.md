# Omarchy Chicago Light

A light Omarchy theme drawn from Chicago's fairgrounds, lakefront skyline, and limestone Water Tower. Warm paper, lake green, and brass frame three archival wallpapers.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-chicago-light.git`, then run `omarchy theme set chicago-light`. Cycle the three wallpapers with `omarchy theme bg next`.

For the companion theme, see [Omarchy Chicago Dark](https://github.com/jacob-vincent-mink/omarchy-chicago-dark).
